TACET Laboratories · Reactor Division

CRITICAL __VERSION__

A synthesizer powered by a reactor. Free custom firmware for the M-VAVE FM-1. The sound comes from a model of a nuclear core: the sixteen white keys are its fuel channels, and your hands pull the control rods. The core rises, settles, poisons itself with xenon and drifts on its own. Push the steam too far, press AZ-5, and it can run away.

What you need

  • An M-VAVE FM-1 and a USB cable that carries data (not a charge-only cable).
  • A computer with Chrome or Edge (Windows, macOS, Linux or ChromeOS). Firefox and Safari can't talk to MIDI devices this way. Chrome on Android also works.
  • About ten minutes. Keep the FM-1 powered by USB the whole time.

There are three steps: install m-bootloader (once), back up your FM-1, install CRITICAL.

1Install m-bootloader (once)

Why this step? For your safety. CRITICAL is only ever installed through m-bootloader, a free, open-source bootloader for the FM-1 by Julius Vitkauskas (MIT licence). It sits under every firmware and makes sure that no firmware, CRITICAL included, can lock you out of your synth:
  • It checks the firmware before starting it. If the firmware is damaged or an install was interrupted, the FM-1 doesn't hang. It opens a recovery menu instead, ready to reinstall from a browser.
  • Hold PLAY while switching on: the recovery menu, with MIDI MODE for browser installs. Hold REC: USB download mode for M-Flasher, without opening the case.
  • Installers that use it read the whole package and check it before erasing anything.
That's why this page refuses to install without it. You only do this step once. Afterwards, any firmware that uses MIDI MODE installs from a browser.

Already have it? Switch the FM-1 off, then on while holding PLAY. If the m-bootloader menu appears, skip to step 2.

Way A · simplest

With M-VAVE's M-UPGRADE app

  1. Your FM-1 must run M-VAVE's own firmware (as it comes from the factory).
  2. Download fm1-uboot.fwsc from the latest m-bootloader release.
  3. Open it in M-UPGRADE, M-VAVE's updater, and start the upgrade.
  4. The FM-1's screen shows the bootloader being written, then it restarts. M-UPGRADE then times out with an error: that's expected, the install is already done.

The package holds no firmware, only a small installer that writes the bootloader. Your firmware and settings stay. If M-UPGRADE refuses a unit running other firmware, its force upgrade skips the model check.

Way B · with a full backup

With M-Flasher

  1. Download M-Flasher for Windows, macOS or Linux (same author, open source).
  2. Back up your whole FM-1 with it first, and keep the file.
  3. Check the FLASH CHIP it reports (see the note below).
  4. Download fm1-uboot.boot from the latest m-bootloader release and install it with M-Flasher's bootloader option (command line: m-flasher bootloader --file fm1-uboot.boot).

M-Flasher writes only the boot area and keeps the chip key the installers need.

Before you write a bootloader:
  • Keep the power on. Losing power while the boot area is written can leave the unit needing a hardware recovery.
  • Newer FM-1s. Units sold from late 2026 may have a different flash chip (UCUN UC25HQ80, JEDEC ID 0xB36014). m-bootloader is little tested on it. Check FLASH CHIP in M-Flasher first. With that chip, installing is at your own risk: read the m-bootloader status notes.
  • M-VAVE's official updates put their own bootloader back. If you install one later, repeat this step.

Check it worked: switch off, then on while holding PLAY. The m-bootloader menu appears.

2Connect and back up

  1. Switch the FM-1 off, then on while holding PLAY. In the menu, choose MIDI MODE with OCT- / OCT+, then press PLAY.
  2. Connect it by USB to this computer, then click 1. Connect below. The browser asks to use MIDI devices: allow it. The page reads the FM-1's chip key.
  3. Click 2. Back up. The page saves the whole flash (1 MB) as a file in your downloads: your current firmware, its settings and its sounds. Keep it. With M-Flasher it puts your FM-1 back exactly as it is now.

3Install CRITICAL

Click 3. Install CRITICAL and wait for the end (about a minute). The FM-1 reads the whole package twice: first to check it (nothing is erased yet), then to write it. Don't unplug, and keep this tab in front: browsers slow down background tabs.

Your first minute

  • The FM-1 restarts on CRITICAL: the plant's terminal logs the operator in. Press PLAY.
  • Turn MASTER up gently. The core starts in hot standby: a bed of counts and low channels.
  • Hold a white key: you pull that channel's rod. Its power rises, then falls back slowly when you let go.
  • ARP keeps rods out. SEQ lets the core play by itself. HOME shows everything. PRESETS changes the scene.
  • Hold PLAY one second: a new plant. Hold SAVE one second: everything is kept for next time.
  • Hold REC one second: AZ-5, every rod in. With the steam high and many rods out, the core may not take it well.

The full guide: docs/GUIDE.md.

Going back

  • Exactly as before: restore the backup from step 2 with M-Flasher (switch on holding REC for download mode).
  • Another firmware: any firmware with a MIDI MODE installer installs over CRITICAL the same way (menu, MIDI MODE, its own page).
  • M-VAVE's firmware: M-UPGRADE needs a firmware it can update. Restore your backup with M-Flasher.

If something goes wrong

  • "No FM-1 in MIDI MODE found": the FM-1 isn't in MIDI MODE (menu, MIDI MODE, PLAY), or the cable carries no data. Try another cable or port, then click Connect again.
  • "The FM-1 is running a firmware": switch it off and on holding PLAY. If no menu appears, m-bootloader isn't installed yet (step 1).
  • The install stopped halfway: nothing is lost. m-bootloader sees the firmware is incomplete and opens its menu by itself. Choose MIDI MODE, reload this page and install again.
  • The browser never asks about MIDI: use Chrome or Edge, from a page opened on your computer, and check that MIDI is allowed in the site's settings.
  • Back up stops: some m-bootloader versions don't answer reads. Make your backup with M-Flasher instead (step 1, way B).
